# Happy Chocolate Pops Website
## About the project:
This website is for a family run business for Happy Chocolate Pops. It is a custom dessert business that 
makes treats specific to the customers order. The goal of this website is to create a reliable and user-friendly 
experience where customers can see the treats we offer, personalize their orders, and request custom-made treats for 
special occasions. 
Happy Chocolate Pops mainly specializes in cake pop designs based on customers' preferences, themes, and celebrations. 
Each order is unique to the customers needs which makes personalization an important part of this website.

## Project Goals:
- Create an attractive and user-friendly website for a family business.
- Develop clear and convenient customer ordering experience.
- Showcase past cake pop designs and available options.
- Practice web development, design, and problem-solving skills.
- Adapt and change the project as the business begins to grow.

## Technologies:
- HTML
- JavaScript

## Project status:
In development.

## Current Focus:
The current focus is to create the foundation of the website and focus on order experience for custom cake pops. Customization includes:
- Variety of occasions and themes
- Colors
- Cake flavors
- Party packages
- Other personalized designs requested by customers

## Future Plans:
Once the website is more developed, established, and organized, we plan to expand the website to include other products such as cookies, cake shooters, brownies, and other exclusive holiday/seasonal treats.
